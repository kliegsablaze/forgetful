Forgetful

One live input, sent by hand into whichever of four tape memories you choose. The moment you move on, it starts forgetting itself — until it's silent, and ready to hold something new.

forgetful v0.3.0 · audio_fx · requires schwung

What it is

One input, four memories

Forgetful holds four independent memories, A through D. Each one can record a loop from whatever's feeding into the module, then plays it back on its own — coming apart a little more with every pass, until it's silent and empty again.

The wearing-out is real, not a fade laid over the top. Each time round, what comes off the tape is written back onto it, so the next pass reads the damaged version and damages it again. Set a knob and leave it: the loop keeps going further, because the damage compounds on itself.

The controls sit on six pages. Main is where you choose which memory is listening and set how fast each plays. Sound is level and tone for all four at once. Then one page each for Loop A through Loop D, where you shape how that memory falls apart.

Send → Rec → plays & comes apart → silent

Setup

Load it into a chain slot

Forgetful isn't in the Schwung module catalog yet, so the Module Store won't find it — install it by hand. Download forgetful-module.tar.gz and unpack it into schwung/modules/audio_fx/ on the Move; the repo has the two commands. Once the catalog entry lands, the Module Store will do it for you.

It's audio_fx, chainable — drop it into any Signal Chain fx slot. No setup, no external files: turn Send to A, press Rec, and it's catching.

Screen — page 1 of 6

Main

The page you land on: which memory is listening, what all four are doing, and how fast each one runs. Click a control to see what it does.

Send
Points the live input at A, B, C or D. Only that one can hear you; the other three keep playing, aging or sitting empty exactly as they were.
ECHO
All four memories at once, one character each in A B C D order, arranged two over two. A dash for empty, R recording, O overdubbing, F frozen, or a digit for roughly how much is left. 9F over -1 reads as A near full, B frozen, C empty, D nearly gone.
REC
One knob, four stages, each press moving to the next. Press to start recording; press again to stop, and it begins playing and wearing out; press while it plays to overdub, layering onto what's there without erasing it or resetting how far it has gone; press again to stop overdubbing. The readout names what the next press does.
Freeze
Stops that memory wearing out — it keeps looping exactly as ruined as it is, indefinitely. Nothing is written back onto the tape while it's frozen, so it holds. Press again to let it carry on. The readout names what it's doing now: FROZEN or AGING.
Speed
Four knobs, one per memory: 1/4, 1/2, 1x, 2x. 1x is home; one detent left is half speed, two is a quarter, one right is double. Changes glide over five seconds rather than jumping. A slowed memory also comes apart more slowly, because the damage happens per pass, not per second — half speed is also a way to preserve one.
Screen — page 2 of 6

Sound

Level over tone, four columns — one per memory. How loud it is, and what's left of it.

Level
How loud each memory sits in the mix, independent of Send. Goes to 150%, so a memory can be pushed as well as pulled back — useful once one has worn down to almost nothing and you want it back. Defaults to 80%.
Tone
A DJ filter, centred. Turn left and it low-passes, sweeping the top away; turn right and it high-passes, sweeping the bottom away. The middle is a true bypass. It's a performance control, not damage: sweeping it changes what you hear without printing anything onto the tape, so you can take the top off and put it back.
Screen — pages 3–6

Loop A, B, C, D

One page per memory, all the same layout. This is where you decide how that memory comes apart, and how much of it plays.

Age
How long, in seconds, this memory takes to go from full to gone — 3 seconds to 5 minutes. Everything else is a rate of damage; this is the clock they run against.
Trim
Picks how much of the recording plays. Centre plays all of it. Turn left and the loop starts later, cutting the front; turn right and it ends earlier, cutting the back. Either way it gets shorter. Nothing is erased — turn back and it returns. The part you've cut off also stops wearing out, since it isn't passing the head, so bring it back later and it sounds as it did when you cut it.
Space
How much of this memory goes into the shared reverb at the end of the chain — a long, dense tail of about six and a half seconds. Post-fader, so turning the memory down turns its send down too. The reverb keeps ringing after you pull the send back.
ECHO
This memory's own state as a single character — the same codes as Main's ECHO, for this one alone.
Warp
A transport that can't hold its speed: a slow sag, a faster flutter, and a drift that wanders at random so it never settles into a pattern. Gentle settings sag; the top of the travel is a machine coming apart.
Darken
The top end going, a little more on every pass. One turn is subtle by design — this is a rate, and what you hear is a few hundred passes of it adding up. Past about halfway a dark reverb wash blends in on top, so the far end is a wall rather than just a dull loop.
VINYL
The medium losing material. A gate that takes the quiet parts first, so what survives is peaks surfacing out of silence rather than holes punched at random — and because it's written back onto the tape, what goes is gone. It bites harder the older the take gets. Freeze stops it.
Hiss
Noise printed onto the tape on every pass, so it accumulates: inaudible on a fresh take, and by the end the loudest thing left. That's the arc — the music disappears and the noise floor doesn't.
How it wears out

The knobs set a rate, not a sound

Warp, Darken, VINYL and Hiss aren't effects laid over the top. Each pass, what comes off the tape is written back onto it, so the next pass reads the damaged version — the same gentle filter applied three hundred times, the same faint noise printed three hundred times.

So a knob sets how fast this falls apart. Turn one a little and nothing dramatic happens immediately; leave it and the loop keeps going further on its own. Turn one a lot and it's gone in under a minute.

The knobs themselves move like knobs — turn one and it slews smoothly to where you put it, no jump, no long glide. Nothing waits for a take to end.

Because the tape is really being rewritten, it can't be undone. Turn Darken up, hear it, turn it back down — the loop stays as dark as it got. The only thing that restores a memory is recording a new one, and when a memory finally goes silent every knob on it returns to its default so the next take starts clean.

Freeze stops all of it. Nothing is written back while a memory is frozen: it holds exactly as ruined as it was.

Two of the eight are not damage. Trim chooses which part plays, and Tone on the Sound page filters what you hear. Both are reversible — turn them back and what they hid comes back.
Ways to use it

What to actually do with it

A few starting points — all of them just combinations of the controls above.

Build and let go
Catch a phrase into A, then send to B and keep playing while A fades quietly underneath. By the time you're done with B, A is barely a memory of itself, sitting low in the mix.
Mismatched clocks
Set each memory's Age wildly differently — one at 10 seconds, one at the full 300 — so the mix is always somewhere between freshly caught and almost gone, and it never settles into a repeating cycle.
Catch and hold
Record a chord or a held note, let Darken and Warp work into it for a while, then Freeze right where it sounds best. A strange, stable pad you can play over for as long as you like.
One clean, one crumbling
Push VINYL and Hiss hard on one memory as a textured bed, and leave another completely untouched. The mix always has one steady voice sitting next to one that's coming apart.
Build it in layers
Record a beat, let it loop a few times, then overdub a second pass on top instead of starting over. Keep adding without ever losing what was already there.
A drift that never repeats
Nudge Warp up a little at a time over a long Age setting. The pitch wanders further with every turn, and by the time the memory is gone it barely resembles where it started.
