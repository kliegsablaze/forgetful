Forgetful

One live input, sent by hand into whichever of four tape memories you choose. The moment you move on, it starts forgetting itself — until it's silent, and ready to hold something new.

forgetful v0.2.0 · audio_fx · requires schwung

What it is

One input, four memories

Forgetful holds four independent memories, A through D. Each one can record a loop from whatever's feeding into the module, then plays that loop back on its own — fading a little more with every repeat, until it's silent and empty again.

The controls are split across two kinds of page: one Main page for choosing which memory is listening right now and mixing all four together, and four memory pages — one each for A, B, C, D — for shaping exactly how that memory falls apart over time.

Send → Rec → plays & ages → silent

Setup

Load it into a chain slot

Install it from Schwung Manager's Module Store, at http://move.local:7700 — it's in the catalog, and updates arrive there too. To do it by hand instead, download forgetful-module.tar.gz and unpack it into schwung/modules/audio_fx/ on the Move; the repo has the two commands.

It's audio_fx, chainable — drop it into any Signal Chain fx slot. No setup, no external files: turn Send to A, press Rec, and it's catching.

Screen — page 0

The Main page

This is the page you land on. It's where you choose which memory is listening, see all four at a glance, and mix them together. Click a control on the screen below to see it light up; the full walkthrough follows underneath.

Send
Turn it to A, B, C, or D. Whichever one it's pointed at is the only memory that can hear the live input right now — the other three keep playing, aging, or sitting empty exactly as they were, no matter where Send points.
ECHO
A read-only glance at all four memories at once, one character per memory in A B C D order: a dash for empty, R while recording, O while overdubbing, F while frozen, or a digit for roughly how much is left before it fades to nothing. 7R-1 reads as A around 70–79%, B recording, C empty, D around 10–19%.
REC
One knob, four stages, each press moving to the next: press once from empty to start recording; press again to stop — the memory starts playing back immediately and begins fading; press again while it's playing to start overdubbing — whatever you play now gets layered onto what's already there, without erasing it or resetting how far along it's faded; press once more to stop overdubbing and return to plain playback. The knob always tells you what the next press will do, not what's happening right now.
Freeze
Pauses that memory's fading completely — it keeps looping exactly as degraded as it already is, for as long as you like. The four flavor knobs on that memory's own page keep working normally while it's frozen, so you can dial in a character and hold it in place. Press again to let it carry on fading from there.
The mixer
Four more knobs, one per memory, set how loud each one sits in the final mix — independent of Send. D can be turned all the way down while it's still recording, or A can be brought back up after it's mostly faded away.
Screen — pages 1–4

A memory page

Pages 1 through 4 — one per memory — share this exact layout. This is where you shape how that one memory ages: how it sounds, how long it takes, and how to let it go.

Age
How long, in seconds, this memory takes to fade to silence once it starts playing back. It also sets the pace for the four flavor knobs below — see how the knobs actually move.
Drive
Tape warmth and saturation. The one knob on this page that isn't turn-based like the others — it eases toward whatever you set it to continuously, rather than snapping or gliding in stages.
ECHO
This one memory's own state, as a single character — the same codes as the Main page's ECHO, just for this memory alone.
Erase
Clears this memory. Empty or recording, it's instant. Playing back, it fades out over 10 seconds instead of cutting — even while frozen — and clears once the fade finishes. Press Rec on it again before that happens and it's yours again immediately, mid-fade.
Warp
Slow, uneven pitch wobble on the read head — a worn tape transport losing its grip.
Darken
Feeds the memory into a small reverb. Turn it up and the wash gets more present, darker, and longer together — at the top, a wall of reverb, not just a filtered signal.
VINYL
Click-and-pop surface crackle. The bottom half of the knob only raises how loud it is; past halfway it also starts getting busier.
Hiss
Brightened, high-passed noise — tape hiss, not static. Kept quiet on purpose: a texture sitting underneath, not a wall of noise.
How the knobs actually move

First touch sets it. Every touch after glides.

Warp, Darken, Hiss and VINYL don't behave like an ordinary knob. The first time you turn one since a take closed, it jumps straight to what you set.

Every turn after that glides instead — from wherever it sits now, toward the new value, timed to arrive exactly when the memory itself runs out of time. However much of Age is left, not the full Age setting.

Try it: the first click below sets the value cold. Every click after glides. Freeze turns every glide into a short, fixed 150ms window — live, knob-following control, for sculpting a memory's character by hand while its aging is held still.

Ways to use it

What to actually do with it

A few starting points — all of them just combinations of the controls above.

Build and let go
Catch a phrase into A, then send to B and keep playing while A fades quietly underneath. By the time you're done with B, A is barely a memory of itself, sitting low in the mix.
Mismatched clocks
Set each memory's Age wildly differently — one at 10 seconds, one at the full 300 — so the mix is always somewhere between freshly caught and almost gone, and it never settles into a repeating cycle.
Catch and hold
Record a chord or a held note, let Darken and Warp work into it for a while, then Freeze right where it sounds best. A strange, stable pad you can play over for as long as you like.
One clean, one crumbling
Push VINYL and Hiss hard on one memory as a textured bed, and leave another completely untouched. The mix always has one steady voice sitting next to one that's coming apart.
Build it in layers
Record a beat, let it loop a few times, then overdub a second pass on top instead of starting over. Keep adding without ever losing what was already there.
A drift that never repeats
Nudge Warp up a little at a time over a long Age setting. The pitch wanders further with every turn, and by the time the memory is gone it barely resembles where it started.
